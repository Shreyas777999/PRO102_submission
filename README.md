# SACS-ORS (Minimal JavaFX Prototype)

## Features
- Add and load farms (data persistence with serialization).
- Extendable to dairies, milk supplies, and deliveries.
- Simple GUI built with JavaFX and FXML.

## Run Instructions
1. Open project in NetBeans or IntelliJ.
2. Ensure JavaFX SDK is configured.
3. Run `Main.java`.

## Note
This is a minimal working prototype, designed for academic submission. Extend as needed.
